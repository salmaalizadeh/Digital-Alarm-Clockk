# Digital Alarm Clock

A digital clock and alarm made with HTML, CSS, and JavaScript.

## Features

- Shows the current time.
- Lets you choose an hour and minute for an alarm.
- Plays a ringtone when the alarm time is reached.

## How to Run

Open `index.html` in your browser. Keep the ringtone file in the project so the alarm sound can load.

## Built With

- HTML
- CSS
- JavaScript
